# 战术织匠 · Tactic Weaver

一款可在浏览器试玩的像素战术肉鸽 MVP。选择同伴、调整站位，用自然语言生成并应用战术，自动战斗后输入一次成长。

## 启动

需要 Node.js 22.19 或更高版本。在本目录运行：

```sh
npm install
npm run dev
```

打开 http://localhost:4173 。开发服务器同时提供网页与 API，默认只监听本机。更换端口可在 `.env` 中设置 `PORT`。

生产构建与本地运行：

```sh
npm run build
npm start
```

## DeepSeek 接入

将 `.env.example` 复制为 `.env`，在本地文件中填写自己的密钥：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-v4-flash
PORT=4173
```

重启服务并刷新页面，右上角将显示“DeepSeek 已连接”。该标识表示服务端已配置密钥；首次生成请求才会验证密钥是否有效。不要将密钥提交到代码仓库或写入前端。

接口使用 `https://api.deepseek.com/chat/completions`，非思考模式、JSON 输出，每次输出上限 650 tokens，25 秒服务端超时。API 错误直接展示，不静默切回本地模式。前端不接收密钥。

未配置密钥时，游戏仍可玩，明确显示“本地演示模式”。该模式只是有限关键词解析，不是 LLM，可尝试界面中的快捷示例。DeepSeek 使用 OpenAI 兼容 HTTP 格式，这里直接调用 HTTP，无需额外 SDK。

## 第一版内容

- 盾卫、射手、刺客三个固定角色，以及不同阵容的人机。
- 六个部署点：先选择同伴，再点击位置；占用时交换。战场获得焦点后也可按 1–6。
- 三场遭遇战加一场重锤首领战。
- 条件战术：最近／远程／低血量目标、保护射手、等待前排、低血后撤、重击闪避。
- 三次成长：攻击、生命、速度、闪避、反击、协同追击。
- 战术预览后应用，强化接受后才消耗奖励。已有单次能力不能重复领取。
- 暂停、双倍速、攻击预警、伤害数字、关键事件与结果面板。
- 每场重新开始时恢复全队生命；失败回到备战，保留已经获得的成长。
- 浏览器本地存档，支持 JSON 导入／导出。未完成的战斗刷新后回到本关备战。

一条完整构筑：第一关后给盾卫“学会躲避重击”，第二关后“成功闪避后强化反击”，第三关后“协同追击”。第二关可以给刺客设置“优先攻击后排”。

全队方针会覆盖三人的当前战术，之后可逐人调整。闪避指令不会凭空解锁能力；角色需要先获得“识破重击”。

## 实现结构

| 文件 | 责任 |
| --- | --- |
| `src/game/engine.ts` | 独立战斗模拟、移动、目标选择、伤害、重击与闪避 |
| `src/game/campaign.ts` | 四关进度、一次性强化、存档检查 |
| `src/game/rules.ts` | 模型输出白名单、策略说明、本地演示解析 |
| `src/game/data.ts` | 角色、遭遇、强化与地图数据 |
| `src/Battlefield.tsx` | Canvas 绘制、固定步长循环、部署交互 |
| `src/App.tsx` | 战术面板、角色卡、流程、存档与复盘 |
| `server/llm.ts` | DeepSeek 请求和模型返回检查 |
| `server/index.ts` | 同源 API、限流、静态／开发服务 |

战斗运行在浏览器，不在每帧调用模型。所有执行动作和数值由游戏定义，模型只选择合法规则。当前是本机单人原型，浏览器存档不是防作弊系统；公开上线前还需要按部署环境补充认证、费用额度和服务端权威进度。

## 美术

角色卡使用本项目已经生成的盾卫、射手、刺客图片（`public/portraits/`）。这些是有背景的概念图，尚未完成透明动画素材。战场使用原创程序绘制的像素小人、石板地面、立柱和特效，保持可玩性；不是把概念图直接当作已完成精灵动画。

测试覆盖真实战斗推进、完整四关正常成长流程、真实重击前摇下的闪避、后排目标选择、奖励单次消费、模型契约与错误可见性。模型调用测试替换外部传输，未消耗真实 API；未提供有效密钥前无法验证真实模型效果和延迟。
